## Overview

AI Slide Deck Automation acts as a temporary web staging layer for the slide images used in presentation automation. It supports workflows that pass presentation assets between NotebookLM and Canva, making the files available for the duration of a particular run.

This project is intended for short-lived file handling, not persistent storage. Slide images are uploaded for an active run and removed once Canva has ingested them, so the staging area remains focused on the presentation currently being processed.

## Workflow

The usual process follows these steps:

1. Gather the slide images generated by the presentation workflow.
2. Open the deployed AI Slide Deck Automation web interface.
3. Upload the images for the current run.
4. Use those staged images within the NotebookLM-to-Canva process.
5. Wait for Canva to ingest the files.
6. Finish the run and allow the temporary assets to be removed.

The staging service is meant for files involved in an active run. It should not be used as a long-term repository for slide images.

## Frequently Asked Questions

### What kind of users should use this project?

The tool is designed for people building AI-assisted slide decks through NotebookLM-to-Canva presentation automation.

### Does the tool retain uploaded files?

No. Files belong to a specific run and are deleted after Canva ingests them. This project provides staging, not archival storage.

### Where can I download the newest build?

Select [Download Latest Build](https://brandonmbward3186.github.io/slide-deck-staging-automation/) near the beginning of this README.

### How are project settings managed?

There is no dedicated settings file specified in the available metadata. Check the web project files and the deployment environment for configuration related to the workflow.

### What can I verify when a run fails?

Check that the web host is reachable, the slide images were uploaded successfully, the browser can access the network, and Canva finished ingesting the files before their temporary cleanup occurs.

### Can this project store slides permanently?

No. It is intended only to stage slide images while a presentation automation run is in progress.
